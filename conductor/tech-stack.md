# Technology Stack

## 1. Programming Languages
-   **Python:** Primary language for backend logic, data processing, machine learning, and Dash application development.

## 2. Frameworks and Libraries

### Web Framework
-   **Dash:** Python framework for building analytical web applications.
-   **Plotly:** For interactive data visualizations within the Dash application.
-   **Dash Bootstrap Components:** For pre-styled, responsive Dash components.

### Audio Processing
-   **Librosa:** For audio analysis, feature extraction, and manipulation.
-   **PyDub:** For high-level audio manipulation and processing.
-   **SoundFile:** For reading and writing audio files.

### Machine Learning
-   **PyTorch (2.9.1 / CUDA 13.0):** Deep learning framework for building and training machine learning models. Project requires Python 3.10+.
-   **Scikit-learn:** For general machine learning tasks and utilities.

### Data Analysis and Manipulation
-   **Pandas:** For data manipulation and analysis, especially with tabular data.
-   **NumPy:** For numerical operations and array processing.

### Database
-   **SQLite:** Lightweight, file-based SQL database for local data storage and management.

### Messaging and Communication
-   **MQTT (Paho-MQTT):** Message queuing telemetry transport protocol for real-time communication, likely with audio devices or sensors.

## 3. Other Tools & Utilities

-   **FFmpeg:** Command-line tool for handling multimedia data, used for audio conversions.
-   **Diskcache:** Disk-backed cache for Python functions.
-   **Requests:** HTTP library for making web requests.
-   **Google API Python Client & OAuthlib:** For integration with Google services.
